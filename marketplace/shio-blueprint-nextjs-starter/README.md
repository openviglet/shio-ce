# Next.js starter

The first-party starter, whole: a Page model, two published pages, and the Next.js App Router project that renders them — catch-all routing, ISR, draft preview, signed revalidation. Same tree as `npm create shio-app`, with the content.

## Install

```
shio marketplace install shio-blueprint-nextjs-starter
```

Then apply it to a site. Applying is a separate step: installing puts the package where
this instance can see it, and nothing is written to your content until you apply it.

## Parameters

- `projectName`: The npm package name of the generated project, also used in the README and the welcome page. Default: `my-shio-site`.

## What it provisions

- 1 post type(s)
- 1 content document(s)
- 13 front-end file(s) for you to write
